## Hi, I'm Umut 👋

**Full-stack Software Engineer.** I build production backends in Go, the web and mobile apps on top of them, and the CI/CD and AI tooling that keeps shipping fast.

---

### ⚙️ Backend & APIs (Go)

- Design and build **REST APIs** with **Gin** and **GORM** on **PostgreSQL**: schema design, migrations and query tuning.
- **Authentication & authorization** with **Keycloak**, OAuth2/OIDC and **JWT**, plus role-based access control and rate limiting.
- **Real-time features** over **WebSockets** and **Redis**, with scheduled background jobs (cron).
- Integrations: **AWS S3** file storage, transactional e-mail, **Firebase** push notifications.
- Generate **Excel and PDF reports** on the server, document APIs with **Swagger / OpenAPI** and cover them with tests (`testify`, `sqlmock`).
- Work on a **microservice platform** in a Go workspace, behind **Caddy**.

### 📱 Web & mobile

- **React Native + Expo** apps for iOS and Android: maps and location, push notifications, **TanStack Query** for server state, **Zustand**, **NativeWind**, automated builds and releases with **EAS**.
- **Next.js + TypeScript** dashboards with **Tailwind CSS** and Radix UI: role-based screens, charts, drag-and-drop layouts and internationalization.

### 🚀 DevOps & tooling

- Containerized services with **Docker** and Docker Compose, infrastructure with **Terraform**.
- **GitHub Actions** pipelines for tests, builds, deployments and secret scanning (gitleaks).
- **Agentic coding** with **Claude Code**: I build **MCP servers**, custom agents and skills that automate everyday development work (scaffolding endpoints, migrations, deploy checks).
