### Side projects

**[SwiftWheels](https://github.com/umuttosun1/Swiftwheels)** — a vehicle rental site built with Spring Boot.
Customers browse, rent for a date range and return from their profile; admins manage the fleet, rentals,
users and revenue. Stock is updated under a row lock so the last car can't be rented twice.
`Spring Boot` `Spring Security` `JPA` `PostgreSQL`

**[HUDUT](https://github.com/umuttosun1/hudut)** — an interactive world map that runs fully offline.
Look up a country to see its land neighbours and World Bank indicators, compare two countries, find the
shortest land route between them, or play the daily border-chain puzzle.
`JavaScript` `D3-geo` `SVG`

**[Car Rental](https://github.com/umuttosun1/Car-Rental-Project)** — the desktop sibling of SwiftWheels.
The business rules live in PostgreSQL (PL/pgSQL functions, procedures and triggers) and the app ships as
a self-contained Windows `.exe`.
`Java Swing` `PostgreSQL` `Gradle`

**Image Processing Lab** — my graduation project: a desktop app for trying 146 image-processing and
data-augmentation algorithms interactively and reading the code behind each one.
`Python` `OpenCV`
