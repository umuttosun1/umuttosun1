### 💼 Nexizon'da neler yapıyorum

- **Arka uç (Go)** — Gin ve GORM ile REST API'ler; PostgreSQL şema tasarımı ve migration'lar,
  Redis önbellekleme, WebSocket ile gerçek zamanlı bildirimler, zamanlanmış işler,
  Keycloak + JWT ile kimlik doğrulama, rate limiting, S3 dosya depolama, e-posta ve push bildirimleri,
  Excel/PDF raporlama, Swagger dokümantasyonu
- **Web paneli (Vue 3)** — Vuetify ve TypeScript ile kapsamlı yönetim paneli; rol tabanlı yetkilendirme,
  çok dilli arayüz, grafikler, takvim ve harita bileşenleri
- **Mobil (React Native)** — Expo ile iOS ve Android uygulaması; konum ve harita, push bildirimleri,
  çevrimdışı dostu veri yönetimi, EAS ile otomatik derleme ve yayın
- **Platform ve DevOps** — Go mikroservisleri, Next.js tabanlı geliştirici paneli,
  Docker, Caddy, Terraform ve GitHub Actions ile CI/CD
- **Yapay zeka destekli geliştirme** — MCP sunucusu ve Claude Code eklentileri (agent'lar ve skill'ler)
  ile ekibin geliştirme akışını otomatikleştiren araçlar
